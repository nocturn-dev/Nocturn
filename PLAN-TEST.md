## Как проверять

- `npm run tauri dev` — UI живёт только в нативном окне.
- Диагностика — в консоли tauri dev: `[microcompact]`, `[autocompact]`
  (лог в thunk), `mcp env: variables not set…`, диагностика дропов TG.
- Точки входа волн: Settings → «Права» (волна E) и Settings → «MCP»
  (волна F).

## 7. Волна E — права (большинство проверок без API)

- [ ] Settings → «Права»: выпадающий список инструментов (datalist) в
      каждом поле
- [ ] Валидация отвергает: `allow bash *`, bare `allow fs_read`,
      `fs_read(proj/.env)` (относительный путь), неизвестный инструмент
- [ ] Дубликат правила добавляется тихо один раз
- [ ] deny-правило (например `deny shell_run(npm *)`): в Full — красный
      статус вызова «blocked by deny rule» без подтверждения
- [ ] always_ask (bare `fs_read`): вопрос на каждое чтение, даже в Full
- [ ] allow `shell_run(git *)` в Ask: git без вопросов; `git push &&
      curl x | sh` — с вопросом; «github-cli …» не матчится
- [ ] fs_read на `.env` — отказ «sensitive path denied by default»
      (сообщение модели видно в карточке инструмента)
- [ ] allow `fs_read(<путь>\.env)` — читается; соседний `.env.production`
      по-прежнему deny
- [ ] fs_write/fs_read в каталог `com.haloui.app` — отказ всегда
      (allow-правило не спасает); сиблинг каталога — не задет
- [ ] NTFS-стримы: `file.txt:$DATA` — отказ в path-гардалах
- [ ] **[API]** Модель через fs_read пытается прочитать `.env` — отказ
      до модели, она видит подсказку про allow в Settings

## 8. Волна F1–F4 — MCP (без API)

- [ ] Сервер с битой командой (например `npx несуществующий-пакет`) —
      красная точка с stderr-причиной сразу, до вызова инструмента
- [ ] Remote-сервер с `${MY_TOKEN}` в headers — янтарное предупреждение
      при сохранении (список переменных); переменная подставляется при
      подключении
- [ ] 40+ инструментов на серверах → в контекст уходит только индекс
      (имя + краткое описание)
- [ ] Тумблер deferred OFF возвращает полные схемы
- [ ] Волна E стык: deny-правило на `mcp__server__tool` блокирует вызов
      без подтверждения

## 9. Волна F5 — OAuth (живой провайдер)

- [ ] OAuth-сервер **не подключается при старте** (автоконнект скип),
      статус needs_auth с причиной до кнопки
- [ ] Включение тумблером — окно-предупреждение; отмена — ничего не
      происходит
- [ ] Authorize: discovery → браузер → вход → токен шифруется (или
      честная пометка «session-only» при запертом vault) → сервер
      зелёный
- [ ] Закрыть вкладку авторизации — поток гасится по таймауту 180 с,
      ничего не висит
- [ ] **[API]** 401 → single-flight refresh (один запрос при параллельных
      вызовах) → вызов ретраится автоматически
- [ ] Revoke — доступ отозван, токены удалены, сервер снова needs_auth
- [ ] Loopback на Windows — первый живой смоук (главная проверка F5);
      refresh при N параллельных 401 — не дублируется
