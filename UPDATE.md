# UPDATE.md — журнал изменений Nocturn

> Правила ведения (обязательно для новых сессий):
>
> 1. **Новые записи добавляются СВЕРХУ** (свежее — выше).
> 2. Формат записи: `## ГГГГ-ММ-ДД · [теги] Название`, под ним 1–4 буллета
>    деталей и **хэш коммита** (коммит обязателен: verify зелёный → коммит → запись).
> 3. Теги (можно несколько через ` · `):
>    - `new-feature` — новая функция
>    - `hot-fix` — быстрый точечный фикс
>    - `global-fix` — фикс, затрагивающий систему/много мест
>    - `rebuild` — переписан механизм/компонент
>    - `update-backend` — тронут Rust (`src-tauri/`)
>    - `update-frontend` — тронут фронтенд (`src/`)
>    - `refactor` — переструктурирование без нового поведения
>    - `experiment` — экспериментальная функция (помечена в UI)
>    - `infra` — инфраструктура/инструменты/правила
>    - `docs` — только документация
> 4. Один логический изменение = одна запись. Большие пачки — одна запись со
>    списком буллетов, не простыня из двадцати записей.
> 5. Старые записи не удалять и не редактировать задним числом.
> 6. Если фикс — рядом одним предложением «причина → что сделано».

## 2026-09-27 · [global-fix · update-backend · update-frontend · infra] Волна аудита: 25 фиксов по итогам тотальной ревизии
- Сборка/платформы: user32-FFI загейчен `#[cfg(windows)]` + ветка native-fullscreen для macOS/Linux; rust-job CI расширена до ubuntu/macos (cargo test линкует — ловит чужие `#[link]`); coli — своя процесс-группа на Unix + страховочный kill (stop/выход больше не висят); Quick Entry позиционируется по монитору курсора.
- Данные/безопасность: `chat-usage` доезжает до фронта на OpenAI-совместимых стримах ([DONE] ≠ abort, единый исчерпывающий emit-хелпер); гардал путей закрыл админ-шары (`c$`/`admin$`, +тесты); vault/заметки/чекпоинты — atomic_write (0600 на Unix); websearch — потолок тела по ходу чтения; websearch.json в экспорте с маской Brave-ключа; capabilities: +allow-hide (Esc/onBlur QuickEntry не работали), −лишние fullscreen-права; perm-канонизация пути — в blocking-пул.
- Фронт/CSS: IME-гарды isComposing в 6 Enter-обработчиках; «Акцент проекта» — инлайн-редактор вместо мёртвого window.prompt; утечка resize-листенера AmbientLayer; дубляжи MainSection сняты; мёртвая анимация usage-arc ожила; reduce-motion покрывает змейку/search-hit; focus-visible ring; userCss до первого рендера; theme-color синхронизируется с темой; превью тем из данных палитры; en-локаль под компиляторной гарантией полноты; Dead code: perm_get, hard-mode, --halo-term-blur, счётчик fs_grep.
- Коммиты `eaf31b5`…`590812a` (25 шт., каждый с зелёным verify fast). Причина → находки тотального read-only аудита (4 субагента + супервизор).

## 2026-09-27 · [rebuild · experiment] Hard-Mode: живой терминал на xterm.js
- CSS-скин заменён **полноэкранным живым PTY-терминалом** (@xterm/xterm + FitAddon, динамический импорт — бандл не растёт): ANSI-цвета, курсор, бэкспейс, scrollback, resize → SIGWINCH.
- Помечено **экспериментальным** (в тумблере и подсказке); Nocturn уходит в «спячку» (UI примонтирован, состояние не теряется), выход — хоткей `hard_mode`.
- Итерации до финала: скин → хоткей вместо /hard → свой PTY+Vt (статтеры/дубли бэкспейса — потолок самодельного VT) → xterm.js. Тумблер только «разрешает» режим, вход — по хоткею.
- Коммиты `4f962b7`, `ef9603b`, `b8b78c5`, `4afe3ec`, фиксы: `6d396c0` (непрозрачный фон поверх glass, печатные символы → PTY, предзамер контейнера), `aa3ee47` (лишняя скобка в CSS ломала vite build).

## 2026-09-27 · [global-fix] F11 «затмение»: окно поверх панели задач
- Native fullscreen на безрамочных окнах бит апстримом (tauri #7473/#7328/#8383) — F11 больше не вызывает его: окно анимированно (один атомарный прыжок) накрывает **весь монитор** — shell сам прячет таскбар.
- **Topmost по фокусу**: ALT+TAB и выбор из панели задач работают (при потере фокуса always-on-top снимается), возврат в Nocturn возвращает затмение.
- Кнопка ⤢ (fullscreen) удалена за ненадобностью и путаницей; действие `toggle_fullscreen` осталось назначаемым (F11 по умолчанию).
- Коммиты `b8b78c5` (частично), финал — в `4afe3ec`-пачке.

## 2026-09-27 · [hot-fix] Трей: зомби-процесс и «мёртвый» Open Nocturn
- Скрытое окно Quick Entry держало процесс живым после закрытия главного окна — трей оставался с нерабочими пунктами (`main window NOT found`). Фикс: закрытие главного окна (`WindowEvent::Destroyed`) = выход приложения.
- «Open Nocturn»/«Clear All Data»: форс-показ (unminimize → show → always-on-top мигнуть → focus) против foreground-lock Windows; диагностика `[tray] …` в консоли dev.
- Коммит `ab05de3` (частично).
