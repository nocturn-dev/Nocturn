# UPDATE.md — журнал изменений Nocturn

> Правила ведения (обязательно для новых сессий):
>
> 1. **Новые записи добавляются СВЕРХУ** (свежее — выше).
> 2. Формат записи: `## ГГГГ-ММ-ДД · [теги] Название`, под ним 1–4 буллета
>    деталей и **хэш коммита** (коммит обязателен: verify зелёный → коммит → запись).
> 3. Теги (можно несколько через ` · `):
>    - `new-feature` — новая функция
>    - `hot-fix` — быстрый точечный фикс
>    - `global-fix` — фикс, затрагивающий систему/много мест
>    - `rebuild` — переписан механизм/компонент
>    - `update-backend` — тронут Rust (`src-tauri/`)
>    - `update-frontend` — тронут фронтенд (`src/`)
>    - `refactor` — переструктурирование без нового поведения
>    - `experiment` — экспериментальная функция (помечена в UI)
>    - `infra` — инфраструктура/инструменты/правила
>    - `docs` — только документация
> 4. Один логический изменение = одна запись. Большие пачки — одна запись со
>    списком буллетов, не простыня из двадцати записей.
> 5. Старые записи не удалять и не редактировать задним числом.
> 6. Если фикс — рядом одним предложением «причина → что сделано».

## 2026-09-27 · [update-backend] Оптимизационный проход по Rust-ядру: 5 коммитов
- P1 **PTY** (`d50ea80`): вывод слипается в 10-мс окно — `cargo build` вместо тысяч IPC-событий в секунду шлёт пачки; `pty-exit` теперь строго после последнего вывода (EOF-маркер по каналу). Латентность ≤10 мс — ниже восприятия.
- P2 **Чат** (`0a6697e`): `DeltaBatcher` — подряд идущие Content/Thought дельты сетевого чанка уезжают одним emit'ом; логика слияния покрыта юнит-тестами (порядок и границы видов сохранены).
- P3 **Настройки** (`9210772`): кэш разобранного settings.json по (mtime,len) — run_tool больше не читает диск на каждый инструмент; расшифровка ключа по-прежнему per-call (расшифрованный ключ в кэш не попадает), инвалидация во всех 4 писателях.
- P4 **perm** (`03eeb79`): корни канонизуются один раз в perm_set (blocking-пул), path_allowed работает с готовым canon-списком; security-семантика не тронута (путь канонизуется как прежде) + unix-тесты path_allowed для ubuntu-CI (windows-тесты с C:\-путями раньше на CI не гонялись вовсе).
- P5/P6 (`b0d36a4`): list_dir без лишнего stat на запись (file_type из readdir), fs_grep exact-case префильтр, кэш tool_schemas (OnceLock).
- Сознательно НЕ тронуто: deep-буферизация PTY/чата (латентность), кэш расшифрованных ключей (секьюрити), memchr-зависимости (потолки и так конечны).
