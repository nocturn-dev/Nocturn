### 2. [СРЕДНИЙ] Крылья в полёте при reduce-motion: базовый кадр продолжает махать, альтернативный кадр становится видимым — двойной спрайт
- Локация: src/index.css -> 1176–1208 (определения), 1230–1243 и 1244–1257 (reduce-списки); носитель src/components/mascot/Nok.tsx -> 738–760
- Категория: prefers-reduced-motion / война каскада / расхождение спека↔код (комментарий 1176–1178: «reduce-motion оставляет базовый»)
- Код:
  ```css

    animation: nok-wing-a calc(0.36s * var(--motion-scale)) linear infinite;
  }
  .nok-wings-alt {
    opacity: 0;
  }
  .nok-fly .nok-wings-alt {
    opacity: 1;
    animation: nok-wing-b calc(0.36s * var(--motion-scale)) linear infinite;
  }
  ```
- Доказательство: два независимых дефекта.
  1) Системный reduce: media-блок глушит `.nok-wings` (0,1,0) — проигрывает `.nok-fly .nok-wings` (0,2,0): взмах (жёсткая смена opacity 1↔0 каждые 0.18s) продолжается.
  2) Оба reduce-механизма гасят `animation` альт-крыльев (`html.motion-reduced .nok-fly .nok-wings-alt` (0,3,1) — 1233; `.nok-fly .nok-wings-alt` (0,2,0) в media — 1248), но НИ ОДИН не восстанавливает `opacity: 0`: правило `.nok-fly .nok-wings-alt { opacity: 1 }` (1205–1208) остаётся в силе → альт-кадр статично виден.

  | элемент | норма | system reduce | ручной toggle |
  |---|---|---|---|
  | базовые крылья `.nok-fly .nok-wings` | машет (0,2,0) | МАШЕТ — (0,1,0) проигрывает | статичен (0,2,1) побеждает |
  | альт-крылья `.nok-fly .nok-wings-alt` | мигает (0,2,0) | статичен ВИДИМ (opacity:1 жив) | статичен ВИДИМ |
- Конфигурация воспроизведения: любая тема; reduce-motion (системный или ручной) + пасхалка «Полетать» (ПКМ по Ноку) — класс `nok-fly` держится ~9s (JS), mood `fly` рендерит альт-кадр (Nok.tsx:751).
- Последствия: во время «полёта» при reduce видны ОБА кадра крыльев одновременно (наложение двух спрайтов), при системном reduce базовый ещё и мигает. Комментарий обещает «reduce-motion оставляет базовый» — не выполняется ни по базовому (системный), ни по альтернативному (оба).
- Рецепт: в оба reduce-блока добавить `.nok-fly .nok-wings` полным селектором (системный) и `opacity: 0`-оверрайд для `.nok-fly .nok-wings-alt` (или переносить скрытие альт-кадра с animation на opacity-пару).
