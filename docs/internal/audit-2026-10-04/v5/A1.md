### 2. [НИЗКИЙ] git_status: unescape не разворачивает восьмеричные эскейпы \NNN — путь манглится
- Локация: src-tauri/src/files.rs -> 188–210 -> git_status_impl
- Категория: тихий отказ

## Приложение В — отклонённые подозрения

1. **checkpoint_restore: fs::write после symlink-проверки (files.rs:784–797)** — теоретическое TOCTOU-окно между проверкой и записью, в отличие от handle-based fs_write. Отклонено: restore — действие пользователя из UI (не агент), снапшот лежит в appdata (запись туда = уже компрометация), проверка есть, окно микроскопическое; форсирование open_write_verified сюда — отдельная задача hardening, не дефект этой версии.
2. **read_capped_string: metadata→read_to_string TOCTOU (fsutil.rs:300–308)** — файл может вырасти между stat и чтением. Отклонено: локальный тот же пользователь вне модели угроз; все потребители — конфиги приложения.
3. **AnthropicAccumulator: повторный message_delta задвоил бы Usage (chat.rs:1534–1549)** — протокол гарантирует один message_delta перед message_stop; flush Usage не эмитит. [ГИПОТЕЗА]-класс для нестандартных прокси; наблюдаемых оснований нет.
4. **final_path_of (Windows) при пути >1024 UTF-16 (fsutil.rs:137–153)** — молчаливая усечка → paths_equivalent=false → отказ. Направление fail-closed, длинники >2048 байт экзотичны.
5. **fs_write без капа content (tools.rs:568–640)** — размер ограничен лимитом токенов провайдера (~сотни КБ на tool_call); cap у vault_write (2МБ) а fs_write нет, но поверхность согласована с провайдерными лимитами.
6. **dictation_transcribe: ложный срез строки с "] " не в таймстампе (dictation.rs:327–335)** — сработает только если строка начинается с '[' и содержит '] ' — страховка при отключённом -nt, косметика.
7. **imagegen resolve_target: enc-ключ cfg блокирует фолбэк на plaintext chat-ключ при запертом vault (imagegen.rs:117–143,175–182)** — непустое поле = «настроено»; ошибка честная («vault is locked»), поведение осознанное.
