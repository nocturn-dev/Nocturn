- Категория: платформенный UX-дефект (Ctrl vs Cmd — инвентарь хоткеев)
- Код:
```tsx
// TerminalPanel.tsx:659-664
if (e.ctrlKey || e.metaKey) {
  // Раскладконезависимо: физические клавиши C/D (на русской C даёт «с»)
  if (e.code === "KeyC") return "\x03"; // SIGINT
  if (e.code === "KeyD") return "\x04"; // EOF
```
- Доказательство: на macOS Cmd+C — конвенция копирования (Terminal.app/iTerm копируют выделение); здесь metaKey отождествлён с ctrlKey и Cmd+C уходит в PTY как 0x03 — активная команда умирает. Пути копирования нет: ни selection->clipboard, ни Ctrl+Shift+C (grep по файлу: единственный clipboard-контекст — вставка, :723). В HardTerminal (xterm.js) копирование есть средствами xterm — расхождение двух терминалов одного приложения.
- Конфигурация воспроизведения: macOS; консоль -> sleep 30 -> выделить вывод -> Cmd+C.
- Последствия: потеря управления терминалом по мышечной памяти macOS; невозможность скопировать вывод в режиме console (данные не теряются, UX-пробел).
- Рецепт: grep -n "metaKey" src/components/TerminalPanel.tsx (:660) + grep -n "copy" src/components/TerminalPanel.tsx -> пусто.
